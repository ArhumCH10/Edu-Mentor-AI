## Development Workflow

### Continuous Integration (CI)
Our CI pipeline runs the following checks on every pull request to the `updated-FYP` branch:

- 🔍 **ESLint Checks**: Ensures code quality and consistency
- 🧪 **Test Coverage**: Runs all unit and integration tests
- 🏗️ **Build Verification**: Confirms the project builds successfully
- 📊 **Performance Budget**: Checks bundle size and performance metrics

### Pull Request Process
1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run local tests and linting
5. Push your branch
6. Open a pull request to `updated-FYP`
7. Wait for CI checks to pass

### Required Checks
- All CI checks must pass
- Minimum test coverage must be maintained
- No merge conflicts with the base branch
